## 六、支付、退款、换 IP：下单前必须知道的规则

这三块是最容易被忽略、事后又最麻烦的部分，官方文档里写得很细，值得提前看一遍。

### 支付方式

支持**支付宝、PayPal、信用卡**。用支付宝有个实际好处：官方退款条款里明确写了，通过支付宝退款时会一并将手续费返还，因此**走支付宝退款不收手续费**。退款到账户余额也不收费，退到其他原路支付方式则要扣支付网关的手续费。

### 退款政策

- **3 天内全额退款**：条件是服务购买不超过 3 天，且虚拟机使用的流量不超过 30GB。退款会扣除支付网关收取的交易手续费。
- **30 天内部分退款**：按实际支付金额计算，比较"已使用流量对应的价值"和"剩余服务时间对应的价值"，取**较高**的那个作为退款依据——这条对用得少的用户相对友好。
- **不予退款的情况**：同一系列产品已退款 3 次、遭遇 DDoS 攻击、以"网络状况不佳"为由、IP 地理位置原因、续费订单、用账户余额支付的订单、以及滥用造成的损失。

一个操作细节：发起退款后实例会立刻被关闭，防止继续消耗流量额度。你也可以先自己关机再发起退款。退款流程确认后实例会被删除，数据无法恢复，该备份的先备份。

### 换 IP 规则

这是 DMIT 比较被认可的一项服务，但 Pro/EB 和 T1 的规则完全不同：

**Pro 和 Eyeball 系列**
- 免费更换：实例购买满 7 天起（第 8 天），距离上次更换（含付费更换）满 15 天，ICMP 和所有 TCP 端口均被封，且服务剩余有效期不少于 7 天。
- 付费更换：购买满 24 小时后可申请，每次 $5。
- 这两条线**保证 IP 首次连接在全球范围内可访问**。

**Tier 1 系列**
- 只能付费更换，每次 $5，距上次更换需满 3 天，服务剩余有效期不少于 3 天。
- **不保证 IP 在全球范围内可用**。买 T1 之前要接受这一点。

另外无论哪个系列，IP 都是系统随机分配的，不能指定 IP 段。后台目前已经支持自助更换，部分线路需要人工审核。

**DMIT 会不会超售？** 官方一直强调不超售，这也是它价格比同类高出一截却仍然有人买的主要原因之一。不过这是商家的自我承诺，第三方测评里能看到一些实际的性能测试数据，但没有人能独立验证宿主机层面的资源分配。

**能测速再买吗？** 官方提供了 Looking Glass 测速页面，各机房都有对应的测试节点，下单前可以先把延迟和路由走一遍。具体测试 IP 会随平台更替变动，以官网当前公布的为准。

**三个机房怎么选？** 大陆用户体感优先 → 香港 Pro；预算优先但不想用普通国际线路 → 洛杉矶 Pro 或 EB；只做国际业务、需要大带宽大流量 → T1，洛杉矶和东京都行；移动用户为主 → 优先看 EB 系列，CMIN2 双程直连的性价比通常比 Pro 更高。
